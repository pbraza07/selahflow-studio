# SelahFlow v1.3.5 — Owner Branding / Full Color Editor
Production: https://selahflow.onrender.com
GitHub: https://github.com/pbraza07/selahflow-studio

Business owners visit /studio/{slug}, click Branding, choose one of **20 complete color palettes**, optionally select **12 heading/body font options**, then customize each of 19 page elements with a color picker or hexadecimal code. A live mock booking preview shows changes before choosing Save & publish theme.

## Color-controlled areas
Page background, header, intro/hero, booking panel, service cards, policy box, footer, primary buttons, hover buttons, secondary buttons, selected services, booking progress steps, inputs/form fields, borders, headings, body text, muted secondary text, links, and accent.

## Font options
DM Sans, Manrope, Inter, Poppins, Montserrat, Lato, Nunito, Roboto, Playfair Display, Merriweather, Georgia, and System UI.

Text is automatically shifted to a readable contrasting shade when a requested color would have less than a 4.5:1 contrast against its background. User-supplied color values must be exactly #RRGGBB; font choices must be members of the allowed set. No arbitrary CSS is accepted.

Themes are stored in the existing per-business settings JSON, with no migration needed. Owner pages, public business profiles and customer booking pages all use the selected theme. The public SelahFlow platform and other owners are not affected. Legacy primary/background settings are used only as a fallback.

This release does not activate subscription payments or AI reception; 6-character minimum passwords remain unchanged.

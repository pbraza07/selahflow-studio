# v1.3.232 verification

Owner booking details now include Membership / Client ID, including past dates. The existing business-scoped prefill endpoint restores name, email, phone, birth date and valid custom registration answers. Changing or clearing the ID clears previous details; canceled lookups ignore stale responses. Confirmation requires a successful lookup when an ID is entered, with manual entry available after clearing it. The server validates the explicit ID against the authenticated owner's roster and matching contact identity, then saves it on the appointment. Existing waiver, capacity, attendance and credit rules remain; no migration.

## Implemented scope

- Owner notification control beside the bell, with current device state, enable/test/disable controls, accessible dialog, and iPhone/iPad Home Screen guidance.
- Opted-in owner devices receive pending session requests independently of optional delegated reviewer routing.
- Additive migration 090 captures new authoritative completed session, cash-session, membership, renewal and package payments into a per-device delivery queue. No historical payment backfill. Tenant scope, active subscriptions, receipt evidence, transaction rollback and duplicate events are checked. Provider acceptance is recorded; uncertain delivery outcomes are not automatically replayed.
- Client acceptance notifications open the private booking status/payment page. Existing authorization and approval/payment eligibility checks remain authoritative. Tokens stay out of notification payloads/URLs. Migration 091 preserves subscriptions while allowing multiple devices per private booking token, with individual device removal.
- Financial stages, revenue summaries and transactions use aligned tables. Activity cards retain detail dialogs. Shared CSS prevents squeezed metrics, currency values and receipt labels. English, Spanish and Portuguese copy is updated.

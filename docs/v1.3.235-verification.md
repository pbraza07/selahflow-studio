# v1.3.235 verification — Gmail connection monitoring

## Scope

Shared sender authorization checks every five minutes while the server worker runs. Automatic retries after transient errors use one-, two-, four-, eight- and then 15-minute delays. Persisted health and incident identifiers survive restarts. Invalid grants wait for explicit Google consent. No automatic browser consent, password entry, inbox access, provider switching, or ambiguous email resend.

The primary administrator sees outage/recovery status and last/next checks in Platform Admin → Shared Gmail sender. The manual check uses the existing primary-only authorization and same-origin POST protections. Deliberate disconnect deletes the connection and stops recovery. The worker logs only allowlisted state, timestamps, counters and opaque incident IDs, for independent monitoring without the failed sender.

## Validation

Focused Gmail and diagnostics suite: 15/15 passed. TypeScript passed. Synthetic regressions cover concurrency, throttling, retry/backoff, recovery, incident deduplication, revoked grants, wrong client setup, missing encryption configuration, refresh-token rotation, scope loss, legacy status repair, explicit disconnect, provider isolation and diagnostic redaction. Existing send-only consent, staging allowlists and ambiguous-send checks pass.

Full suite, production build, GitHub CI and Render rollout pending. No real email was sent or Gmail account disconnected for testing.

## External requirements

Google refresh tokens with a revoked/expired grant require user authorization. Google external OAuth apps in Testing can issue seven-day refresh tokens for Gmail scopes. Publishing/verification is controlled in Google Cloud and has not been changed by this release. References: https://developers.google.com/identity/protocols/oauth2 and https://developers.google.com/identity/protocols/oauth2/web-server.

Independent conditional notification configuration and live heartbeat evidence will be recorded after rollout. Private settings and tokens are not exposed in the public health endpoint.

# v1.3.128 — private calendar team accountability

Open **Calendar → Team accountability · owner only**. The tool is removed from Overview. Choose dates (up to 93 days), select a configured session or booked service appointment, or use **Assign team** on a list row. Check accountable team members, add an optional private note, and select **Save private team assignment**. Uncheck everyone and save to mark that record Unassigned. The **List view / Hide accountability list** button controls the sortable list. The list shows session/service name, date, Eastern start/end time, team member names, record/status, assignment source and private note. Calendar date changes select that day; range controls allow longer tracking review. Open date in calendar returns to a listed record’s date.

Session rows represent the configured occurrence; service appointment rows represent individual booked records and identify the client when available. They are labelled separately. Existing default hosts are shown until a private override is saved. Assignments and notes are private; they do not reassign public booking hosts, alter client choices/receipts, change availability or consume capacity. Existing per-member hiding and service/session booking defaults remain in Settings. This tracks owner-entered accountability, not proof of attendance or payroll.

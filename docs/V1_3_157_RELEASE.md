# v1.3.157 — Discovery business logos

Discovery results use each active business's saved Branding logo. Businesses without a logo, or whose logo fails to load, show the official SelahFlow symbol. Images use a fixed 50-pixel frame with contain sizing so the full logo remains visible. Logo update timestamps version the image URL so a saved replacement is reflected after refreshing results.

The marketplace returns only logo availability and version metadata; logo bytes continue through the existing active-business branding endpoint. No migration, payment, email, provider or customer-record changes.
